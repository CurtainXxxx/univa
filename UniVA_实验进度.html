排错记录
已修复的问题
每个修复都让链路更稳定

① Wavespeed 轮询 SSL 断连崩溃

修复：新增 _get_with_retry 指数退避重试，14 处轮询全替换。

② 本机代理拦截大请求

修复：全局 session 禁用代理，提交/轮询/下载直连。

③ MCP 工具返回类型注解错误

修复：text2video 等 4 工具注解改 Dict/ToolResponse，视频不再"生成了却报失败"。

④ 视觉模型 key 无效 → 接入 DashScope

修复：接 qwen-vl-max，query_llm / video_process 加 .env 覆盖。

⑤ video_editing 未注册 + Runway 失效

修复：注册编辑工具进 prod，style_transfer 改走 VACE。

⑥ 多图故事视频生成失败

修复：AI 规划时编造了不存在的图片路径——改为只用你真实提供的图，生成的目录名也做了安全处理。已完整验证：3 个 5s 片段 → ffmpeg 无损拼接 → 15 秒成片（363 帧，864×496）。补齐：系统无 ffmpeg，装 imageio-ffmpeg 自带二进制解决。

⑦ 问答任务偶发崩溃

修复：规划失败时不再报错崩溃，而是返回明确提示信息。

⑧ lvu 评测口径修正

发现：只测第 1 问 + 32 帧只有 60%；改成每条视频全部 QA（选择题字母匹配 + 简答题 LLM judge）+ 64 帧后达到 74.8%，与论文 76% 基本一致。评测口径决定结论。

⑨ long_video_edit 实现 + 三个坑

实现：重写长视频编辑工具（原版是 Linux 硬编码 + VLM probing 不可用）：ffmpeg 切 5s 片 → 云端 VACE 逐片编辑 → 失败片原片顶替 → 拼接。坑1：切分文件名扩展名被 replace 吞掉导致 ffmpeg 报错；坑2：VACE 要求 duration≥5，末片 4.8s 报 400；坑3：抽样模式只拼编辑段丢了中间内容（307s→31s），已重构为按时间轴插回原片。

⑩ 成本教训：VACE 单次约 $0.5

实测：lve 12 片 + v2v 6 片共 18 次调用，7 次成功即耗掉 ~$3.5 余额（第 8 次起 Insufficient credits）。比预估贵 3-5 倍。全片编辑 $6/条不可持续 → 改用 max_clips 抽样。等充值后再跑。

⑪ SingleAgent 对照实现

实现：结论2 对照——SingleAgent（一个模型同时规划+执行，一次对话连环调工具）vs Plan-Act（双 Agent 分工）。runner 新增 --mode single，与 agent 模式共用同一 MCP 连接与 session 记忆，只差分工方式。

⑫ 环境统一 + 成本护栏

环境：项目真实环境是 venv（agno 2.7.2），之前误用 base python（agno 2.8.7 把 system 映射成 developer role 导致 DeepSeek 报错）。评测统一用 venv + PATH 前缀。护栏：SingleAgent 加 tool_call_limit=10 + 单轮 600s 超时 + "禁止重复生成"指令；runner 执行前写 pending 标记防中断丢结果。实锤：SingleAgent 首次测试 Wavespeed 扣了 2 笔（模型把同一生成任务提交了 2 次，护栏前无限制）。
